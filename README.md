projeto de analise de dados com Machine Learning

com o problema de uma pele com acne, pensei em fazer um projeto que prevesse qual sabor de whey tinha mais chance de dar acne. 

pontos a se considerar: 
- foi utilizado somente uma marca de suplementos (variedade baixa)
- para ter uma analise melhor, precisava-se de dados de pessoas, entao pedi para a IA me gerar aleatorios.
- pela baixa variedade de dados, a maquina deu overfitting, entao a precisao estava muita alta para a quantidade de dados.

para o futuro: utilizar dados de wheys de outras marcas de suplementação e fazer pesquisas reais com pessoas que consumiram determinado sabor.
